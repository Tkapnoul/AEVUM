# Οδηγός εγκατάστασης AEVUM (για εσένα και την παρέα)

## 1. Ο server (μία φορά)

Το AEVUM χρειάζεται έναν server με HTTPS ώστε να το βρίσκουν τα κινητά. Δύο εύκολοι τρόποι:

**Α. VPS (προτείνεται, ~4–5 €/μήνα, π.χ. Hetzner)**
1. Φτιάξε ένα VPS με Ubuntu και εγκατέστησε Docker.
2. Βάλε ένα domain (π.χ. `aevum.toonomasou.gr`) να δείχνει στη IP του.
3. `git clone` το repo, αντέγραψε το `.env.example` σε `.env` και συμπλήρωσε:
   - `DOMAIN` = το domain σου
   - `JWT_SECRET` = ένα μεγάλο τυχαίο κείμενο (`openssl rand -hex 32`)
   - `ANTHROPIC_API_KEY` = κλειδί από https://console.anthropic.com (χρειάζεται για AI, βιολογική ηλικία και ανάγνωση εξετάσεων)
4. `docker compose up -d`. Το HTTPS ρυθμίζεται μόνο του.

**Β. Στον υπολογιστή σου**: `npm install && npm run build && npm start` και μετά `tailscale funnel 8787` (δωρεάν, δίνει μόνιμη διεύθυνση https://….ts.net). Ο υπολογιστής πρέπει να μένει ανοιχτός.

## 2. Λογαριασμοί

- **Ο πρώτος που κάνει εγγραφή γίνεται διαχειριστής.** Κάν' το εσύ πρώτος.
- Οι φίλοι κάνουν εγγραφή από την εφαρμογή.
- Από **Προφίλ → Διαχείριση χρηστών** ορίζεις ποιος είναι coach, γιατρός, διατροφολόγος ή φυσικοθεραπευτής. Μπαίνει αυτόματα στην ομάδα όλων και μπορεί να δέχεται ραντεβού 1-1 (Δευ–Παρ 09–17, αλλάζει από το Προφίλ του).

## 3. Android

1. GitHub → **Actions → Android app** → τελευταίο πράσινο run → **Artifacts → aevum-android**. Ή, αν το έτρεξες με *publish*, από **Releases → android-latest**.
2. Στείλε το `aevum.apk` στους φίλους και άνοιξέ το στο κινητό (επέτρεψε «εγκατάσταση από άγνωστες πηγές»).
3. Στην είσοδο γράψε τη διεύθυνση του server.
4. **Προφίλ → Συσκευές & συγχρονισμός → Health Connect → Σύνδεση** και επέτρεψε όλα τα δεδομένα.
5. Φρόντισε η εφαρμογή του ρολογιού να γράφει στο Health Connect:
   - Samsung Health: Ρυθμίσεις → Health Connect
   - Garmin Connect: Ρυθμίσεις → Health Connect
   - Fitbit / Pixel Watch: Ρυθμίσεις → Health Connect
   - Zepp (Amazfit): Προφίλ → Προσθήκη λογαριασμών → Health Connect
   - Oura, Whoop, Withings, Polar, Coros, Xiaomi: «Health Connect» στις ρυθμίσεις τους

Συγχρονίζει μόνο του κάθε φορά που ανοίγεις την εφαρμογή.

## 4. iPhone

Επίλεξε ένα από τα παρακάτω:

- **Εφαρμογή AEVUM για iPhone**: χρειάζεται Mac με Xcode (`npx cap open ios`, Signing & Capabilities → Team). Με δωρεάν Apple ID η εφαρμογή λήγει κάθε 7 μέρες. Με πληρωμένο λογαριασμό (99 $/έτος) τη μοιράζεις στους φίλους με TestFlight.
- **Health Auto Export** (από το App Store, η αυτόματη αποστολή είναι στη premium έκδοση): στέλνει αυτόματα τα δεδομένα του Apple Health κάθε ώρα. Οδηγίες και token: **Προφίλ → Συσκευές & συγχρονισμός → Health Auto Export**.
- **Αρχείο εξαγωγής** (δωρεάν, χειροκίνητα): Υγεία → εικόνα προφίλ → Εξαγωγή όλων των δεδομένων υγείας → στο AEVUM, **Συσκευές → Αρχείο εξαγωγής Apple Health**.

Στο iPhone χωρίς την εγγενή εφαρμογή, άνοιξε το AEVUM στο Safari και κάνε Κοινοποίηση → «Προσθήκη στην οικ. οθόνη». Έτσι ανοίγει σαν κανονική εφαρμογή.

## 5. Βιολογική ηλικία

1. **Προφίλ → Στοιχεία**: βάλε ημερομηνία γέννησης, φύλο και ύψος.
2. **Δεδομένα → Εξετάσεις → Φωτογραφία ή PDF εξετάσεων**: το AI διαβάζει τις τιμές, τις ελέγχεις και τις αποθηκεύεις. Για PhenoAge χρειάζονται: λευκωματίνη, κρεατινίνη, γλυκόζη, CRP, λεμφοκύτταρα %, MCV, RDW, αλκαλική φωσφατάση, λευκά αιμοσφαίρια (μια απλή γενική αίματος με βιοχημικές και CRP).
3. **Σήμερα → Βιολογική ηλικία → Υπολόγισε**. Παίρνει 1–2 λεπτά. Ξανατρέξ' το κάθε λίγες εβδομάδες για να βλέπεις την πορεία σου.

Η εκτίμηση γίνεται πιο ακριβής με VO₂max (Apple Watch, Garmin), HRV και πρόσφατες εξετάσεις.
